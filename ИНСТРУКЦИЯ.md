# 📘 Инструкция по сайту ReallyWorld (донат-магазин)

Это сайт магазина привилегий для Minecraft-сервера с **админкой**, приёмом
оплат (FreeKassa, ЮMoney, Robokassa, Stripe), авто-выдачей через RCON и
полной настройкой внешнего вида.

Документ объясняет: как запустить, как войти в админку и что в ней делать.

---

## ЧАСТЬ 1. ЗАПУСК

Сайту нужен **PHP + MySQL**. Проще всего — XAMPP (он уже установлен).

### Вариант А — для разработки/проверки (быстро)
1. Открой **XAMPP Control Panel** → нажми **Start** у строки **MySQL**.
2. В папке сайта запусти двойным кликом **`start-backend.bat`**.
3. Откроется браузер на `http://localhost:8080`.

> Минус варианта А: не действует файл `.htaccess` (защита служебных папок).
> Для постоянной работы используй вариант Б.

### Вариант Б — «по-настоящему» (рекомендуется)
1. В XAMPP нажми **Start** у **Apache** и у **MySQL**.
2. Скопируй папку сайта в `C:\xampp\htdocs\` (например `C:\xampp\htdocs\shop`).
3. Открой `http://localhost/shop/`.

### Первая установка базы (делается один раз)
1. Открой **phpMyAdmin**: `http://localhost/phpmyadmin`
2. Слева **New** → имя базы **`reallyworld`** → кодировка **utf8mb4** → Create.
3. Открой в браузере **установщик**:
   `http://localhost:8080/app/install.php` (или `.../shop/app/install.php`)
   — он создаст таблицы, зальёт товары и попросит **логин/пароль администратора**.
4. После установки **удали файл `app/install.php`** (он больше не нужен).

> Данные MySQL (логин/пароль) задаются в `app/config.php`. На XAMPP по
> умолчанию пользователь `root` без пароля — менять ничего не надо.

## ЧАСТЬ 2. АДМИНКА

### Как войти
- Адрес: **`http://localhost:8080/cp-7a93f1c4/`** (не забудь `/` в конце).
  `cp-7a93f1c4` — это секретная папка, её **нет ни в одном файле сайта**,
  поэтому копировщики сайта её не находят.
- **Логин:** `admin`  **Пароль:** `admin123` (заданные при установке).

### ⚠️ Сразу после первого входа сделай 2 вещи
1. **Смени пароль:** вкладка **«Настройки»** → поле «Новый пароль» → Сохранить.
2. **Переименуй секретную папку:** переименуй папку `cp-7a93f1c4` во что-то
   своё (например `kx7-panel-92`) и впиши то же имя в `app/config.php`
   в строке `define('ADMIN_DIR', '...')`. Это твой личный «секретный URL».

### Вкладки админки

#### 🧾 Заказы
Список всех покупок: номер, дата, привилегия, ник игрока, сумма, касса,
статус (оплачен / в ожидании / отменён). Сверху — счётчики и выручка.

#### 💳 Кассы
Включение и настройка платёжных систем. У каждой кассы:
- галочка «Включить» + поля для ключей (берутся в личном кабинете кассы);
- готовый **«URL уведомлений»** — его нужно вписать в кабинете кассы
  (туда касса сообщает об оплате).

| Касса | Что вписать |
|---|---|
| FreeKassa | ID магазина, Секрет 1, Секрет 2 |
| Robokassa | MerchantLogin, Пароль #1, Пароль #2 (есть тестовый режим) |
| ЮMoney | Номер кошелька, секрет HTTP-уведомлений |
| Stripe | Secret key, Webhook secret, валюта, курс |

> Если **ни одна** касса не включена — в окне покупки честно пишется
> «Способы оплаты сейчас не подключены».
>
> ВАЖНО: чтобы оплаты реально проходили, сайт должен быть в интернете
> (белый домен/IP). На `localhost` касса не сможет прислать уведомление.

#### 🎁 Привилегии
Добавление / изменение / удаление товаров. У каждого:
- **фото** (загрузка файла или ссылка), **название**;
- **категория** (вкладка магазина) и **раздел** (подзаголовок);
- **цена** и **старая цена** (если задана — рисуется бейдж «СКИДКА»);
- **команда выдачи (RCON)** — выполнится на сервере после оплаты.
  Можно использовать: `{nick}` (ник игрока), `{priv}` (название), `{amount}`;
- галочка «Активна» — показывать ли в магазине.

Кнопка **«Удалить привилегию»** — внизу формы редактирования.

#### 🗂 Категории
Вкладки магазина (Гриф. Выживание / Анархия / СТО и любые свои).
Можно добавлять, переименовывать, удалять, менять порядок.
- Категорию **с товарами удалить нельзя** — сначала перенеси/удали товары.
- Новая категория сразу появляется вкладкой на сайте.

#### 🎨 Сайт (внешний вид)
Меняет сайт без правки кода:
- **Основное:** заголовок вкладки, логотип (2 слова + картинка), акцентный цвет;
- **Дизайн:** фон страницы, цвет текста, шрифт (Mazzard или Google-шрифты),
  фон главного экрана, **фавикон** (иконка во вкладке браузера);
- **Сервер:** IP сервера (кнопка «копировать IP»);
- **Главный экран:** заголовок (2 строки) и подзаголовок;
- **Соцсети:** ВК, Discord, YouTube, Форум, Telegram;
- **Документы:** ссылки на оферту, политику ПД, политику Mojang;
- **Подвал:** копирайт, ИП/компания, ИНН, ОГРНИП, e-mail.

> Пустое поле = оставить как есть. После сохранения обнови сайт `Ctrl+F5`.

#### ⚙️ Настройки
- **Базовый URL** сайта (для ссылок-уведомлений касс) — указывай при заливке на хостинг;
- **валюта**, **разрешённые IP** админки, **смена пароля**;
- **RCON** (авто-выдача): включить, хост, порт, пароль + кнопка
  «Проверить соединение» (покажет результат сразу под кнопкой).

## ЧАСТЬ 3. КАК ЭТО РАБОТАЕТ ДЛЯ ПОКУПАТЕЛЯ

1. Игрок на сайте кликает по привилегии → открывается окно покупки.
2. Вводит игровой **ник** → жмёт «Купить привилегию».
3. Видит **доступные способы оплаты** → выбирает → попадает на оплату кассы.
4. После оплаты касса присылает уведомление на сайт → заказ помечается
   «оплачен», и (если включён RCON) **команда выдачи выполняется на сервере**.
5. Игрок возвращается на страницу «Оплата получена».

---

## ЧАСТЬ 4. ВЫХОД В БОЕВОЙ РЕЖИМ (реальные оплаты)

1. Залей папку на хостинг/VPS с **PHP 8 + MySQL** и доменом (желательно HTTPS).
2. В `app/config.php` впиши данные MySQL хостинга.
3. Открой `/app/install.php` (создаст таблицы) → задай админа → **удали install.php**.
4. В админке → «Настройки» укажи **Базовый URL** (например `https://твойдомен.ру`).
5. В админке → «Кассы» включи кассы, впиши ключи, скопируй **URL уведомлений**
   в личные кабинеты касс. Для Stripe добавь webhook с событием
   `checkout.session.completed`.
6. В «Привилегиях» пропиши команды выдачи, в «Настройках» включи RCON
   (на сервере в `server.properties`: `enable-rcon=true`, `rcon.port`, `rcon.password`).

## ЧАСТЬ 5. ЧАСТЫЕ ВОПРОСЫ

- **Открыл сайт — нет стилей/картинок.** Открывай через сервер (XAMPP/локалхост),
  а не двойным кликом по `index.html`. И жми `Ctrl+F5` (сброс кэша).
- **В окне покупки «нет способов оплаты».** Ни одна касса не включена в админке
  (или сайт запущен без PHP).
- **Кнопка «Проверить соединение» RCON пишет ошибку.** Значит сайт не достучался
  до сервера: проверь, что RCON включён на сервере и порт доступен.
- **Счётчик «онлайн» показывает 0.** Ему нужен живой API игрового сервера —
  в этой копии данные брать неоткуда.
- **Забыл секретный адрес админки.** Смотри `define('ADMIN_DIR', ...)` в `app/config.php`.
