# Запуск Telegram-бота Eternity-1 (клиенту: 3 шага)

Готовый плагин уже собран: `plugin/dist/TelegramLink.jar` — Maven ставить **не нужно**.

## Шаг 1 — получить токен бота
1. В Telegram открой @BotFather → `/newbot` → придумай имя и юзернейм.
2. Скопируй выданный токен (вида `123456:AA...`).
3. Узнай свой Telegram ID у бота @userinfobot (нужен для админ-команд).

## Шаг 2 — настроить и запустить бота
На машине, где будет крутиться бот (проще всего — та же, что и Minecraft-сервер):
1. Запусти `bot\setup.bat` — вставь токен и свой ID, он поставит зависимости.
2. Запусти `bot\start-bot.bat` — бот начнёт работать (окно держи открытым).

> Бот работает в режиме polling, публичный URL не нужен.

## Шаг 3 — поставить плагин на сервер
1. Скопируй `plugin/dist/TelegramLink.jar` в папку `plugins/` твоего Purpur/Paper-сервера.
2. Запусти/перезапусти сервер (создастся `plugins/TelegramLink/config.yml`).
3. В `config.yml` укажи `bot_url`:
   - бот на той же машине: `http://localhost:3001`
   - бот на другом хосте: `http://IP:3001` (порт = `BOT_API_PORT` бота)
4. `/reload` или перезапуск сервера.

## Готово — как пользуются игроки
1. Игрок пишет боту `/start`.
2. Бот просит ник и выдаёт код, напр. `A1B2C3`.
3. Игрок в игре вводит `/verify A1B2C3`.
4. Аккаунты связаны, бот пишет «Готово!» и начинает слать уведомления.

## Команды бота
- `/start` — привязать аккаунт.
- `/profile` — профиль (ник, UUID, статус в игре, группы LuckPerms).
- `/status` — онлайн сервера (нужен RCON).
- `/shop` — магазин привилегий (кнопки → ссылка на оплату на сайте).
- `/help` — список команд.
- `/cancel` — отменить привязку.

Админ (только твой ID): `/links` (кто привязан), `/broadcast <текст>` (рассылка).

## Доп. настройки (bot/.env)
- `RCON_*` — если заполнено, бот видит онлайн и группы игрока, а после
  привязки шлёт команду на сервер (`RCON_ON_VERIFY`).
- `SITE_URL` — адрес сайта для кнопки в `/shop`.
- `NOTIFY_GROUP_ID` — ID группы, куда дублировать уведомления с сервера.
- Линки хранятся в `data/botlinks.json` рядом с сайтом.
