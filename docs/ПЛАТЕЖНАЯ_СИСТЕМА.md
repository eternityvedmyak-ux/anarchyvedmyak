# Полная инструкция: подключение платёжной системы

Эта инструкция для владельца сервера (админа сайта). После настройки покупатели смогут оплачивать донаты картой, СБП и ЮMoney, а товары будут выдаваться только после реальной оплаты.

## Что подключаем
Рекомендую **Lava** (lava.ru) — российский платёжный агрегатор: карты, СБП, ЮMoney в одном окне, есть API и webhook-уведомления. Ниже — пошагово.

## Шаг 1. Регистрация в Lava
1. Зайди на https://lava.ru, зарегистрируйся как продавец.
2. Пройди верификацию (пары полей + реквизиты для вывода средств на карту/СБП).
3. В кабинете найди:
   - **Shop ID** (он же Merchant ID) — идентификатор магазина.
   - **Secret Key (секретный ключ / apiKey)** — нужен для подписи и проверки уведомлений. Никому не показывай.

## Шаг 2. Включи способы оплаты (карта, СБП, ЮMoney)
В кабинете Lava → «Способы приёма» (или настройки магазина) поставь галочки:
- Банковские карты (Visa / Mastercard / МИР)
- **СБП** (быстрые платежи по QR из приложения банка)
- ЮMoney (опционально)

Больше ничего подключать не надо — покупатель выберет удобный способ прямо на странице Lava. Наш сайт только перенаправляет на неё.

## Шаг 3. Впиши ключи в админку сайта
1. Открой `https://твой-домен/admin` → раздел **«Платёжная система»**.
2. Заполни:
   - Провайдер → `Lava`
   - Merchant ID (shopId) → вставь свой Shop ID
   - Секретный ключ (apiKey) → вставь Secret Key
3. Жми **«Сохранить изменения»**.

## Шаг 4. Настрой webhook (обязательно!)
Webhook — адрес, куда Lava пришлёт подтверждение «деньги пришли». Без него заказы не будут помечаться оплаченными.
1. В том же разделе админки скопируй **Webhook-URL** (выглядит как `https://твой-домен/api/payments/webhook`).
2. В кабинете Lava (настройки уведомлений / Webhook) вставь этот URL.
3. Метод уведомления — POST, формат — JSON.

## Шаг 5. Укажи домен сайта
В файле окружения (`.env.local` на сервере или переменные на хостинге Vercel/Netlify) добавь:
```
NEXT_PUBLIC_SITE_URL=https://твой-домен
```
Без этого Lava не сможет вернуть покупателя на сайт после оплаты.

## Шаг 6. Проверка
1. Открой магазин, нажми «Купить» на любом товаре, введи ник.
2. Должен произойти редирект на `pay.lava.ru` с суммой и номером заказа.
3. Оплати тестово (или реально) → вернёшься на сайт с «Спасибо за оплату».
4. В админке → раздел **«Заказы»** заказ должен стать «Оплачен».

## Безопасность (важно)
- Товар **НЕЛЬЗЯ получить бесплатно**. Заказ помечается оплаченным только по подписанному уведомлению от Lava (подпись проверяется секретным ключом).
- Подтверждающий эндпоинт защищён: ручное подтверждение доступно только из админки.
- Пока платёжка не подключена, кнопка «Купить» просто сообщает, что оплата недоступна (товар не выдаётся).

## Если нужен другой шлюз (ЮKassa / CloudPayments / Prodamus)
Код заточен под Lava, но расширяется легко — вся логика подписи в одном файле `lib/payments.js`. Для другого провайдера смени алгоритм подписи под его документацию и добавь ветку в `buildPayUrl` / `verifyLavaNotification`, либо обратись к разработчику.

## Траблшутинг
- **Нет редиректа на оплату / белый экран после оплаты** — проверь `NEXT_PUBLIC_SITE_URL` и что сайт доступен по HTTPS извне.
- **Заказы висят «ожидает»** — не приходит webhook: проверь URL вебхука в Lava и что твой домен отвечает `200` по адресу `/api/payments/webhook`.
- **«Оплата недоступна»** — в админке не выбран провайдер `Lava` или пустые ключи `merchantId` / `apiKey`.
- **Деньги списались, но выдачи нет** — убедись, что вебхук настроен и домен доступен; при необходимости подтверди заказ вручную в админке («Заказы» → «Подтвердить»).
