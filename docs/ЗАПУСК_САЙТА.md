# Инструкция по запуску сайта

Этот сайт сделан на **Next.js 14** (React). Ниже — как открыть его у себя, локально и в интернете.

## 1. Что нужно установить (один раз)
- **Node.js версии 18 или новее** — скачай с https://nodejs.org (ставь «LTS»). Проверь в терминале:
  ```
  node -v
  npm -v
  ```

## 2. Запуск на своём компьютере (локально)
1. Распакуй папку с сайтом.
2. Открой в этой папке терминал (в проводнике — удерживай `Shift` + правая кнопка мыши → «Открыть окно терминала здесь»).
3. Установи зависимости (делается один раз):
   ```
   npm install
   ```
4. Запусти сайт:
   ```
   npm run dev
   ```
5. Открой в браузере: **http://localhost:3000**

Для работы на сервере (продакшн) вместо `npm run dev` используй:
```
npm run build
npm start
```

## 3. Как открыть сайт в интернете (для всех)
Сайт нужно «залить» на хостинг. Проще всего и бесплатно — **Vercel**:
1. Зарегистрируйся на https://vercel.com (можно через GitHub).
2. В папке сайта выполни в терминале:
   ```
   npx vercel
   ```
3. Следуй подсказкам (логин, подтверждение). В конце получишь адрес вида `https://твой-сайт.vercel.app` — его и давай всем.

> Альтернатива — Netlify, Render или любой хостинг с поддержкой Node.js.

## 4. Админ-панель (редактирование контента)
- Открой: **/admin** (например, `http://localhost:3000/admin` или `https://твой-сайт.vercel.app/admin`).
- Логин и пароль по умолчанию (их нужно сменить, см. файл `.env.local`):
  - логин: `admin`
  - пароль: `eternity123`
- Там меняются: название/описание сервера, IP, цены, донаты, команды, юр. данные, соцсети, платёжная система.

⚠️ Обязательно поменяй пароль админки в файле `.env.local` (`ADMIN_LOGIN` и `ADMIN_PASSWORD`) перед публикацией.
