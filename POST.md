## 📝 Вариант 1: длинный пост для форума (BB-code / Markdown)

> ### 🎮 Бесплатный донат-сайт для Minecraft — полный исходник
>
> Раздаю **готовый донат-магазин** для Minecraft-сервера. Собран на чистом PHP + SQLite, всё работает «из коробки» — распаковал, запустил один `.bat` и пользуешься.
>
> #### Что умеет
> ✅ Магазин привилегий (фото, цена, скидка, разделы, категории)
> ✅ **Кейсы с выбором количества** — игрок берёт сколько нужно, цена пересчитывается, команда выдачи получает количество
> ✅ Покупка игровой валюты слайдером (свой курс, имя, шаг)
> ✅ **Промокоды** — % и фикс. скидки, сроки, лимиты
> ✅ **Авто-выдача через RCON** после оплаты (можно несколько команд)
> ✅ **4 платёжки**: FreeKassa, ЮMoney, Robokassa, Stripe (иностранные карты)
> ✅ **Онлайн-счётчик** игроков (SLP или RCON `list` для реального онлайна)
> ✅ Блок «Последние покупки» с замаскированными никами
> ✅ **Админка** по секретному URL с логином/паролем — настраивается ВСЁ:
>   • товары, категории, промокоды, поиск по заказам
>   • дизайн (цвета, шрифт, фон, логотип, фавикон)
>   • тексты главной, ссылки соцсетей, реквизиты подвала
>   • кассы, RCON (с кнопкой «Проверить соединение»)
>
> #### Требования
> 🔹 PHP 8.0+ (хостинг или [XAMPP](https://www.apachefriends.org/ru/) локально)
> 🔹 SQLite (встроена) **или** MySQL/MariaDB — на ваш выбор
> 🔹 Любой Minecraft-сервер с включённым RCON
>
> #### Установка
> ```
> 1. Распаковать архив
> 2. Запустить start-backend.bat (Windows) или развернуть на хостинге
> 3. Открыть /app/install.php → создать админа
> 4. Зайти в админку → настроить кассы и RCON
> 5. Принимать донат 💸
> ```
>
> Подробная инструкция и пошаговый гайд для хостинга — внутри архива (`README.md`, `ИНСТРУКЦИЯ.md`, `ХОСТИНГ-ispmanager.md`).
>

> [НАЗВАНИЕ-АРХИВА].zip (~26 МБ)
> 🔗 *ссылка-на-файл*
>
> #### ⚠️ Важно
> - Раздаю **бесплатно**, без поддержки и гарантий
> - Использую дизайн публичного зеркала одного Minecraft-сайта. Если у правообладателя есть возражения — удалю по первой просьбе
> - **Не несу ответственности** за то, как вы это используете. Подключать настоящие кассы и принимать платежи — на свой риск, в рамках закона

## ✅ Чеклист перед публикацией

- [ ] В архиве **нет** твоей БД (`app/data/shop.sqlite`)
- [ ] В архиве **нет** твоих логов (`payment/callbacks.log`)
- [ ] В архиве **нет** твоих загруженных картинок (`images/privileges/uploads/`, `public/uploads/`)
- [ ] В `app/config.php` `APP_SECRET` стоит **плейсхолдер**, а не твой реальный секрет
- [ ] Во всех HTML/PHP **нет** твоих ников, IP сервера, Discord-ссылок, e-mail
- [ ] Никакие платёжные ключи / RCON-пароли **не попали** в архив
- [ ] Прикрепил скриншот главной и скриншот админки (по желанию)
