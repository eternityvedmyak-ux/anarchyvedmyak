# 🚀 Размещение сайта на хостинге (ispmanager)

Пошаговая инструкция, как залить этот донат-магазин на хостинг с панелью
**ispmanager**. Суть: залить файлы → создать БД → прописать данные в конфиг →
прогнать установщик → выпустить SSL → настроить кассы.

---

## 1. Что нужно
- Тариф/сервер с **PHP 8.0+** и **MySQL/MariaDB** (в ispmanager есть из коробки).
- **Домен** или поддомен.
- Желательно **SSL** (для приёма оплат — обязательно).

## 2. Создать сайт в ispmanager
1. **Сайты** → **Создать сайт** → укажи домен (напр. `shop.example.ru`).
2. Выбери **PHP 8.x**. Режим «PHP как модуль Apache» предпочтительнее —
   тогда гарантированно работает `.htaccess`. «PHP-FPM (Nginx)» тоже подойдёт,
   но см. раздел про Nginx ниже.
3. Запомни **корневую папку сайта (docroot)** — обычно
   `/var/www/ПОЛЬЗОВАТЕЛЬ/data/www/shop.example.ru`.

## 3. Залить файлы
- Используй **Менеджер файлов** в ispmanager (или FTP/SFTP — данные в разделе
  «FTP-пользователи»).
- Положи **внутренности** папки `reallyworld.ru` (т.е. `index.html`, `app/`,
  `api/`, `css/`, `js/`, `payment/`, `cp-7a93f1c4/`, `images/`, `fonts/` и т.д.)
  **прямо в корень сайта (docroot)** — чтобы `index.html` открывался по адресу
  домена напрямую.
- Удобно загрузить **zip-архивом** и распаковать в панели.

## 4. Создать базу данных
1. **Базы данных** → **Создать** → имя базы (напр. `shop`), кодировка **utf8mb4**.
2. Создай **пользователя БД** + пароль, привяжи к базе (полные права).
3. Запиши: имя БД, пользователь, пароль, хост (обычно `localhost`).

## 5. Прописать данные в конфиг
Открой **`app/config.php`** и заполни:
```php
define('DB_HOST', 'localhost');
define('DB_NAME', 'shop');            // имя твоей БД
define('DB_USER', 'shop_user');       // пользователь БД
define('DB_PASS', 'твой_пароль');

define('ADMIN_DIR', 'свой-секретный-путь');  // + переименуй папку cp-7a93f1c4 в это же имя
define('APP_SECRET', 'длинная_случайная_строка');
define('APP_DEBUG', 0);               // на проде отладку выключить
```

## 6. Установка
1. Открой в браузере **`https://домен/app/install.php`** — создаст таблицы,
   зальёт товары и попросит **логин/пароль администратора**.
2. **Удали `app/install.php`** через менеджер файлов.

## 7. SSL и финал
1. ispmanager → **SSL-сертификаты** → выпусти бесплатный **Let's Encrypt**,
   включи редирект на HTTPS.
2. Войди в админку: **`https://домен/свой-секретный-путь/`**.
3. **Настройки** → **Базовый URL** = `https://домен` (нужно для уведомлений касс).
4. **Кассы** → включи нужные, впиши ключи, скопируй «URL уведомлений» в кабинеты
   касс. На реальном домене webhook'и заработают по-настоящему.

## 8. Права на папку загрузок
Чтобы работала загрузка фото в админке, у папки
**`images/privileges/uploads/`** должны быть права на запись (обычно `755`,
владелец — пользователь сайта). В менеджере файлов: ПКМ → «Атрибуты» → `755`.

---

## ⚠️ Важные нюансы

### .htaccess / Nginx
Защита служебных файлов (`app/`, `*.sql`, `*.log`, `*.md`) сделана через
`.htaccess` и работает при **Apache**. В ispmanager Apache обычно стоит как
бэкенд за Nginx — тогда всё ок. Если сайт **чисто на Nginx + PHP-FPM**,
`.htaccess` не действует — добавь в конфиг Nginx сайта примерно такие правила:
```nginx
# закрыть служебные папки и файлы
location ^~ /app/ {
    location = /app/install.php { } # временно открыть для установки, потом убрать
    deny all; return 404;
}
location ~* \.(sql|log|md|bat)$ { deny all; return 404; }
location ~* ^/images/privileges/uploads/.*\.(php|phtml|cgi|pl)$ { deny all; return 404; }
```
(после установки строку про `install.php` убрать).

### RCON-выдача
Заработает, только если хостинг сможет достучаться до **IP:порта RCON** твоего
игрового сервера. Часто нужно открыть порт в файрволе.

### Оплаты
- На реальном домене (особенно HTTPS) уведомления касс приходят корректно.
- Для Stripe добавь endpoint вебхука и событие `checkout.session.completed`.

### Кэш
После заливки/изменений в браузере жми `Ctrl+F5`.
