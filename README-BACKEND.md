# ReallyWorld — backend (PHP + MySQL)

Динамическая часть: БД, админка, приём оплат (FreeKassa, ЮMoney, Robokassa, Stripe).

## Что где лежит
```
app/            конфиг, подключение к БД, хелперы, классы касс, установщик
  config.php    ← данные MySQL и секретное имя папки админки
  install.php   ← одноразовый установщик (после установки удалить!)
  gateways/     ← FreeKassa, Robokassa, YooMoney, Stripe
api/
  methods.php   GET  — список включённых способов оплаты (для окна покупки)
  create.php    POST — создаёт заказ, возвращает ссылку на оплату
payment/
  callback.php  приём уведомлений касс (?gw=freekassa|robokassa|yoomoney|stripe)
  success.php / fail.php — страницы возврата покупателя
cp-7a93f1c4/    АДМИНКА (секретная папка, нигде не залинкована)
schema.sql      дамп структуры БД
```

## Установка (XAMPP, Windows)

> Важно: запускать под **Apache (XAMPP)**, а не `python` и не `php -S` — только
> Apache читает `.htaccess`, который закрывает `app/` и дампы от посторонних.

1. Запустите **XAMPP Control Panel** → Start у **Apache** и **MySQL**.
2. Поместите папку `reallyworld.ru` в `C:\xampp\htdocs\` (или настройте VirtualHost
   с DocumentRoot на эту папку).
3. Создайте базу: phpMyAdmin → New → имя `reallyworld` → кодировка `utf8mb4`.
4. Откройте `app/config.php` и впишите данные MySQL (на XAMPP по умолчанию
   `root` без пароля — уже стоит).
5. Откройте в браузере **`/app/install.php`** — он создаст таблицы, зальёт 29
   привилегий и попросит задать **логин/пароль администратора**.
6. **Удалите `app/install.php`**.

## Админка

- Адрес: `/cp-7a93f1c4/` — это **секретная папка**. Её нет ни в одном файле фронта,
  поэтому копировщик сайта её не утащит.
- **Переименуйте папку** `cp-7a93f1c4` во что-то своё (можно вложенно) и впишите
  новое имя в `ADMIN_DIR` в `app/config.php`.
- Вход — по логину/паролю (из установщика). Можно дополнительно ограничить по IP
  во вкладке «Настройки».
- Вкладки: **Заказы**, **Кассы** (вкл/выкл + ключи), **Привилегии** (полный
  редактор), **Настройки** (базовый URL, валюта, IP, смена пароля, RCON).

## Управление привилегиями (вкладка «Привилегии»)

Полный редактор — добавить / изменить / удалить. У каждой привилегии:
- **фото** — загрузка файла (jpg/png/webp/gif, до 4 МБ) или ссылка;
- **название**, **категория** (вкладка магазина), **раздел** (подзаголовок);
- **цена** и **старая цена** (скидка — если задана, рисуется бейдж «СКИДКА»);
- **команда выдачи (RCON)** — выполнится на сервере после оплаты.
  Плейсхолдеры: `{nick}`, `{priv}`, `{amount}`, `{order}`.
- галочка **активна** — показывать ли в магазине.

Витрина на главной строится из БД (`/api/privileges.php`): что включено в
админке — то и видно на сайте, вкладки категорий рабочие. Если бэкенда нет
(открыли как статику) — остаются карточки из HTML.

## Категории (вкладка «Категории»)

Категории — это **вкладки магазина** (Гриф. Выживание / Анархия / СТО и любые
свои). Можно добавлять / переименовывать / удалять и задавать порядок и
активность. Вкладки на сайте строятся из этого списка автоматически.
- При переименовании категории привязка у привилегий обновляется автоматически.
- Удалить категорию, в которой есть привилегии, нельзя — сначала перенесите
  (смените категорию у привилегий) или удалите их.

Добавлять можно товары любого типа (привилегии, сундуки, валюту и т.п.) —
в редакторе это одна сущность «привилегия» с произвольной категорией и разделом.

## Внешний вид сайта (вкладка «Сайт»)

Меняется без правки кода — настройки применяются к страницам скриптом
`js/site.js` (как и витрина). Доступно:
- **Заголовок вкладки** (title), **логотип** (два слова + картинка),
- **фавикон** (логотип во вкладке браузера) — файл или ссылка,
- **дизайн**: акцентный цвет (кнопки/ценники/прогресс/окно покупки),
  **фон страницы**, **цвет текста**, **шрифт** (Mazzard или Google-шрифты:
  Roboto, Montserrat, Oswald и др.), **фон главного экрана** (картинка),
- **IP сервера** (кнопка «копировать IP» во всех местах),
- **главный экран**: заголовок (2 строки) и подзаголовок,
- **соцсети**: ВК, Discord, YouTube, Форум, Telegram,
- **документы**: ссылки на оферту, политику ПД, политику Mojang,
- **подвал**: копирайт, ИП/компания, ИНН, ОГРНИП, e-mail.

Изменения видны на всех основных страницах (главная, описание, оплата, anydesk).
После сохранения обновите страницу с `Ctrl+F5`.

## Авто-выдача через RCON (вкладка «Настройки»)

Включите RCON на сервере Minecraft (`server.properties`:
`enable-rcon=true`, `rcon.port=25575`, `rcon.password=...`), затем в админке
включите авто-выдачу и впишите хост/порт/пароль. Кнопка «Проверить соединение»
шлёт серверу `list`. После успешной оплаты команда из карточки привилегии
выполняется автоматически (с подстановкой ника), заказ помечается выданным.

## Подключение касс

Во вкладке «Кассы» включите нужную и впишите ключи. Рядом показан **URL уведомлений** —
впишите его в личном кабинете кассы:

| Касса      | Что ввести в админке | URL уведомлений (Result/Notification) |
|------------|----------------------|----------------------------------------|
| FreeKassa  | ID магазина, Секрет 1, Секрет 2 | `/payment/callback.php?gw=freekassa` |
| Robokassa  | MerchantLogin, Пароль#1, Пароль#2 | `/payment/callback.php?gw=robokassa` |
| ЮMoney     | Номер кошелька, секрет HTTP-уведомлений | `/payment/callback.php?gw=yoomoney` |
| Stripe     | Secret key, Webhook secret, валюта, курс | `/payment/callback.php?gw=stripe` |

> Если ни одна касса не включена — в окне покупки честно пишется
> «Способы оплаты сейчас не подключены».

## Боевой режим (приём реальных оплат)

Кассы шлют уведомления на ваш сервер, поэтому нужен **публичный домен/белый IP**
(на `localhost` уведомления не дойдут):

1. Разверните папку на хостинге/VPS с PHP 8 + MySQL и доменом (HTTPS).
2. В админке → «Настройки» укажите **Базовый URL** (напр. `https://reallyworld.ru`).
3. Скопируйте URL уведомлений в кабинеты касс.
4. Для Stripe добавьте endpoint вебхука и событие `checkout.session.completed`.

## Локальный тест без Apache

Быстро проверить можно встроенным сервером PHP (но `.htaccess` тогда не действует):
запустите `start-backend.bat`. MySQL должен быть запущен (XAMPP).
