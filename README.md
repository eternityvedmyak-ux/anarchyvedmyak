# 🎮 ReallyWorld — Minecraft donate-shop

Полнофункциональный донат-сайт для Minecraft-сервера: магазин привилегий, продажа игровой валюты, авто-выдача через RCON, приём платежей через **FreeKassa / ЮMoney / Robokassa / Stripe**. Админка с настройкой всего: товары, категории, промокоды, способы оплаты, дизайн, тексты, реквизиты, RCON. БД — **SQLite (по умолчанию, без установки)** или MySQL.

> **Это бесплатный исходник.** Раздаётся как есть, без поддержки и гарантий.
> Базируется на дизайне одного из публичных Minecraft-проектов.

## ✨ Возможности

### 🛍 Магазин
- **Привилегии** — товары с фото, ценой, скидкой, описанием, разделами (Донат-привилегии, Кейсы, Сундуки, Услуги и т.д.)
- **Категории-вкладки** — «Гриф. Выживание», «Анархия», «СТО» и любые свои (создаются в админке)
- **Кейсы с выбором количества** — покупатель выбирает, сколько штук взять; цена пересчитывается на сервере; в RCON-команду подставляется количество (`cases give {nick} kits {amount}`)
- **Игровая валюта (Риллики)** — слайдер с настраиваемым шагом, мин/макс, курсом, своим именем («Coins», «Gold», что угодно)
- **Промокоды** — процентная или фиксированная скидка, срок действия, лимит использований
- **Покупка без регистрации** — игрок вводит ник, выбирает способ оплаты, получает товар по RCON

### 🔐 Админка
Доступна по **секретному URL** (не угадывается, не светится во фронте) с логином и паролем.
- **Товары** — добавить / редактировать / удалить / массовое удаление через чекбоксы
- **Категории** — создание собственных вкладок магазина
- **Промокоды** — создание и управление
- **Заказы** — список с поиском по нику / товару / промокоду / статусу
- **Способы оплаты** — включение касс, ввод ключей, копирование URL колбэков
- **RCON** — хост, порт, пароль, тестовая кнопка «Проверить соединение»
- **Настройка сайта** — *всё меняется без правки кода*:
  - название и заголовок вкладки
  - логотип (картинка + текстовый «лого»)
  - фавикон (иконка в браузере)
  - IP сервера
  - заголовки и подзаголовки на главной
  - соцсети (пустые поля автоматически прячут иконку)
  - цвета (основной, фон, текст), шрифт, фоновое изображение героя
  - реквизиты в подвале, ссылки на оферту/политику/Mojang
  - блок «Последние покупки» — включить/выключить, цвета, количество карточек

### 💳 Платежи
Включаются и настраиваются в админке. На сайте показываются только включённые.
- **FreeKassa** — РФ-карты, СБП
- **ЮMoney** (Quickpay) — кошельки и карты ЮMoney
- **Robokassa** — РФ-карты, СБП, кошельки
- **Stripe** — иностранные карты (USD/EUR, авто-конверсия из RUB по курсу из админки)
- Если кассы не подключены — в модалке вежливо пишется *«Способы оплаты сейчас не подключены»*

Все ключи и подписи (md5/sha1/HMAC) валидируются на сервере. Цена приходит с фронта — но **проверяется и пересчитывается на бэкенде** (защита от подмены через DevTools).

### 🎮 RCON-выдача
После подтверждения оплаты сайт автоматически выполняет команду на Minecraft-сервере по протоколу Source RCON:
- Несколько команд — каждая на новой строке
- Плейсхолдеры: `{nick}` `{player}` `{user}`, `{priv}`, `{amount}`, `{qty}`, `{price}`, `{order}`
- Для кейсов с количеством `{amount}` = количество, для валюты `{amount}` = количество монет

### 🟢 Статус сервера (real-time)
Онлайн-счётчик игроков на главной. Два источника:
- **SLP** (Server List Ping) — быстрый, показывает то, что объявляет сервер
- **RCON** `list` — реальный онлайн (на случай, если сервер накручивает SLP)

Если сервер недоступен — отображается **«оффлайн»**.

### 🛡 Безопасность
- Секретный URL админки (по умолчанию `cp-7a93f1c4` — поменяйте на свой)
- Сессии + CSRF-токены в админке
- Все запросы — prepared statements (SQL-инъекции невозможны)
- Загрузка картинок проверяется через `getimagesize` + whitelist расширений + `php_flag engine off` на `uploads/`
- `hash_equals` для сравнения подписей касс и пароля админа

## 🚀 Быстрый старт (локально, Windows)

**Что нужно:** [XAMPP](https://www.apachefriends.org/ru/) (PHP 8.2+). MySQL не обязателен — по умолчанию используется SQLite.

```text
1. Распакуй архив в любую папку
2. Двойной клик по start-backend.bat
3. Откроется браузер на /app/install.php
4. Придумай логин и пароль администратора → "Сохранить"
5. Готово. Главная: http://localhost:8080
   Админка:  http://localhost:8080/cp-7a93f1c4  (логин/пароль из шага 4)
```

**Что произойдёт на шаге 3:** скрипт сам создаст все таблицы в `app/data/shop.sqlite`, зальёт 29 стартовых привилегий и категории — никакого `phpmyadmin` руками настраивать не нужно.

## 🌐 Заливка на хостинг

Подробная пошаговая инструкция: **[ХОСТИНГ-ispmanager.md](ХОСТИНГ-ispmanager.md)** (для ispmanager / DirectAdmin / cPanel — принцип одинаковый).

Кратко:
1. Распакуй файлы в корень сайта (`public_html/`)
2. Поставь права `755` на папки, `644` на файлы; `777` на `app/data/` и `public/uploads/` (чтобы PHP мог писать)
3. Открой `https://твой-домен/app/install.php` → создай админа
4. **Удали** `app/install.php` после установки (или защити его)
5. В админке настрой платёжки и RCON, скопируй URL колбэков в личные кабинеты касс

## ⚙️ Что обязательно поменять перед публикацией

| Файл / место | Что | Зачем |
|---|---|---|
| `app/config.php` → `APP_SECRET` | Сменить плейсхолдер на свою длинную случайную строку | Соль для подписи сессий админки |
| `app/config.php` → `ADMIN_DIR` | Сменить `cp-7a93f1c4` на свой секретный путь | Чтобы админка не открывалась по предсказуемому URL |
| `app/config.php` → `APP_DEBUG` | Поставить `0` на проде | Чтобы ошибки не светились пользователям |
| `cp-7a93f1c4/` | Переименовать папку под новый ADMIN_DIR | Иначе админка не откроется |
| `app/install.php` | **Удалить после установки** | Чтобы никто не сбросил админа |

Когда выкатишь на хостинг с HTTPS — в админке во вкладке **«Общие»** впиши `Базовый URL` (например, `https://example.com`). Это нужно для корректных колбэков касс.

## 🤝 Подключение касс — куда что вписать

В админке во вкладке **«Кассы»** каждая платёжка отображает свой URL уведомлений. Вид у всех одинаковый:

```
https://ваш-сайт/payment/callback.php?gw=freekassa
https://ваш-сайт/payment/callback.php?gw=robokassa
https://ваш-сайт/payment/callback.php?gw=yoomoney
https://ваш-сайт/payment/callback.php?gw=stripe
```

Эти URL копируются в личный кабинет каждой кассы. Дальше:

- **FreeKassa** → Merchant ID + Secret 1 (signature) + Secret 2 (callback)
- **Robokassa** → Login + Password 1 + Password 2 (+ тестовый режим)
- **ЮMoney** → Receiver (номер кошелька) + Secret (HMAC из настройки уведомлений)
- **Stripe** → Secret Key (sk_…) + Webhook Secret (whsec_…) + валюта + курс

Если данных кассы нет — **просто оставь её выключенной**, она не появится на сайте.

## ❓ FAQ

**Можно ли продавать иностранцам?**
Да, для этого включён Stripe. В админке настраивается валюта (USD/EUR) и курс конверсии из рубля.

**Что если у меня MySQL вместо SQLite?**
В `app/config.php` поменяй `DB_DRIVER` на `mysql`, заполни логин/пароль/имя БД. Схема — в `schema.sql`. Остальное (привилегии, настройки) тот же `install.php` сделает.

**Где хранятся пароли?**
Пароль админа — `password_hash` (bcrypt) в таблице `settings`. RCON-пароль — обычная строка (это требование протокола Source RCON, но он шлётся только локально или внутри VPN).

**Откуда брать привилегии для seed.json?**
Уже есть 29 стартовых (GOD, DRAGON, IMPERATOR и т.д.). Через админку можно добавлять/удалять/менять.

**Можно ли отключить блок «Покупка валюты»?**
Да — в админке «Сайт» → флажок «Включить валюту». Снимешь — слайдер исчезнет.

**Можно ли менять дизайн без правки кода?**
Цвета, шрифт, фон, тексты, логотип, фавикон, ссылки — да, всё в админке. Глубже (раскладку, верстку) — нужно править HTML/CSS.
